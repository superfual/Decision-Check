# Decision Check — 发展方向

个人投资者需要理解信号证据、核对成本与盈亏，并判断加仓是否符合自身投资组合约束。

拟议方案：

1. 已有 Wyckoff–SMC 智能体：输出证据、规则检查与数据不足状态。
2. 投资组合计算器：平均成本、已实现及未实现盈亏、现金储备与风险预算。
3. TapeOut：检查明确编码的公开规则。

目前提供 EN/VI/简体中文本地交互原型，支持手动输入、平均成本、未实现盈亏、现金储备与配置比例检查。尚未连接智能体、账户，也未部署 Decision Check 的新电路。

下一步：导入真实智能体报告 → 完善交易账本 → 验证数值比较电路 → 提供可重跑记录。

例如：市场条件满足，但加仓使配置比例达到 60%，超过 40% 上限，因此不满足规则。这不是盈利保证。

相同数据和固定版本的确定性计算才能复现同一项检查。电路不能自行证明账户数据完整或市场判断正确。
