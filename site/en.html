A clear role for every component.

01 · Agent analysis

Price and volume → Wyckoff/SMC evidence. Each assessment needs a timestamp, data source and rule version. This page does not call the agent yet.

02 · TapeOut checks

Prioritize numeric comparison circuits for reserves and allocation, then combine them with signals. Design, cost measurement and verification must precede deployment.

Clear boundaries. Meaningful verification.

How does the existing agent fit in?

Reuse the creator’s Wyckoff–SMC methodology and agent code as the analysis foundation. This prototype illustrates the integration flow; it has no live data and does not present simulated signals as actual agent outputs.

How do average cost, PnL and risk differ?

This page calculates average cost and unrealized PnL for a sample position. Full account PnL requires a buy/sell ledger, fees, deposits/withdrawals and cost-basis rules. Loss budgeting at an exit price is a future step, not part of the current check.

What would TapeOut verify?

A deployed circuit can check logic on supplied inputs. It cannot establish that account data is complete or a market assessment is correct. Reports need inputs, a rule version, circuit ID and read block; this new design has no deployed circuit ID yet.

Next steps

1. Standardize agent outputs and read-only portfolio data. 2. Test the PnL calculator. 3. Build and verify numeric circuits. 4. Let users rerun reports. Automated trade execution is a separate scope.
