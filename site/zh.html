Decision Check 的工作流程

先了解组合，再检验机会。

01 · Portfolio Insider Agent

描述现有现货币种和稳定币，再确定下一步计划。Agent 计算净资产、权重、平均成本、未实现盈亏及两项风险限额。目标资产不必是已有持仓。

02A · Wyckoff Agent

完成 Portfolio Insider 后，分析计划资产的价格与成交量背景。按所选周期检查交易区间、事件顺序和确认条件；缺乏证据不会被强制判为 TRUE。

02B · SMC Agent

与 Wyckoff 独立运行，使用同一份已校验数据。分析结构、流动性扫单及仍有效的价格区域。看涨/看跌方向与满足某项完整交易设置的条件分开呈现。

一项决策，三个视角，理由清晰。

从哪里开始？

打开 Portfolio Insider Agent，描述组合与计划，点击分析计划。第 03 步随后启用 Wyckoff–SMC，沿用所选资产、产品和时间框架。首页的市场 Agent 标签用于展示流程，不是跳过组合输入的独立入口。

持有 OKB 和 USDT，也能检验买入 BNB 吗？

可以。当前持仓与计划资产分开输入。Portfolio Insider 将已列出的资产和仓位计入整体风险，检验新增 BNB 对可用资金与亏损容忍度的影响。Wyckoff 和 SMC 分析计划中的资产，不自动扫描所有币种。

Wyckoff 和 SMC 的数据来自哪里？

市场分析为计划中的资产请求 Binance 现货公开数据。先校验已收盘 K 线、历史长度、时间间隔连续性、重复与缺失。周期投资使用月/周/日，波段使用日/H4/H1，短线使用 H4/H1/M15。来源不可用或历史不足时显示数据不足，不切换交易所。目前尚不支持其他交易所适配器。

如何理解成本、盈亏与可接受亏损？

现货未实现盈亏 = 数量 ×（当前价 − 平均成本）。单项资产的亏损容忍度以成本/开仓价的百分比输入，并自动换算对应价格。这是自填余额分析，不是完整交易账本、手续费或资金费率对账，也不会放置止损单。

两项风险限额有何区别？

单次决策预算按原计划投入金额及该次可接受亏损比例计算；周期限额按固定净资产基准及计划后的整个组合计算。两者共同限制投入金额；亏损或加仓后不会自动重置基准。降低均价不会消除已有亏损。

三个 Agent 如何协作？

Portfolio Insider 先确定组合状态与计划范围。Wyckoff 和 SMC 接收同一快照，但不读取彼此结论作为输入。后续检查将市场条件与原计划金额对应的组合限额结合。每个分支分别显示有效性与通过/未通过；缺失数据或范围不匹配时无法下结论。合约和期权不属于当前试验版。

TapeOut 目前参与到哪一步？

已实现本地三分支布尔模拟，并测试六个有效性/通过位的全部 64 种组合。这还不是已部署的 TapeOut 电路。下一步是确定规则、数值编码和位宽上限，构建亏损预算与净资产下限比较电路，评估成本并验证设计。当前结果不是链上证明。

X Layer 将记录什么？

计划在设计验证后部署 Decision Check 电路，并在 X Layer 记录必要引用。记录将区分输入、规则版本、电路身份及适用时的读取区块或交易。本流程目前未部署新电路，也不发送交易，不会公开完整个人组合。

可以重新检验结果吗？

可导出包含输入与报告的 JSON 记录。保留相同数据与代码/规则版本即可重新计算对照。修改投入金额是创建新方案，不是改写原结果。哈希用于识别数据，不能证明账户历史完整或市场判断正确。

接下来发展什么？

优化三个 Agent 的解释并测试更多实际情形，改善数据覆盖与报告对照，标准化定量输入，以设计、测试并在 X Layer 部署 TapeOut 电路。私人账户同步属于后续阶段。目前产品专注分析决策，不执行交易。
